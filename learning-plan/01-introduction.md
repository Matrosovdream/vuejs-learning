# 01 — Introduction to Vue.js

## Goals
- Understand what Vue.js is and what problem it solves.
- Know where Vue fits among other frontend frameworks (React, Angular, Svelte).
- Get a mental model of how a Vue app is structured.

## Concepts
- **What is Vue?** A progressive JavaScript framework for building user interfaces. "Progressive" = you can use as little or as much of it as you need.
- **Vue 2 vs Vue 3** — we're learning Vue 3 (current). Two coding styles inside Vue 3: **Options API** (older, object-based) and **Composition API** (newer, function-based). We default to Composition API.
- **Single-File Components (SFC)** — `.vue` files with `<template>`, `<script>`, `<style>` in one file.
- **Reactivity** — when data changes, the UI updates automatically.
- **The ecosystem** — Vite (build tool), Vue Router (routing), Pinia (state), Vue DevTools (browser extension).

## Exercises
1. Skim the official Vue intro: https://vuejs.org/guide/introduction.html
2. Open https://play.vuejs.org/ — change the `msg` value and see the preview update. Get a feel for SFCs.
3. Ask Claude to compare Vue's mental model to anything you already know (React, jQuery, plain JS).
